## Optional helper reuse

Read actual source before execution. Match the helper to an authorized outcome and constrain its filesystem, network and browser effects. Important audit observations include:

- Direction helpers write project outputs and user-home history, randomize layout and contain unresolved catalog references. They should not select a new direction for the approved portfolio.
- Browser inspectors can serve local files, launch profiles, overwrite screenshots and capture too early for the official loader. Their generic image/motion quotas and incomplete state/error coverage do not replace project QA.
- Media helpers contact external providers and download files/credits. Validate origin, license, size/type, destination and any SVG before trusted use. No automatic stock portrait or fabricated content should fill an unresolved content decision.
- Global base CSS/reveal scripts can alter the approved layout or strand content; any useful technique must be scoped to the actual component and lifecycle.

Review and adaptation are task-specific. A static audit does not certify helper runtime behavior. If a source or required asset is unavailable, state the gap and continue only the work supported by available evidence.
