# Ranz.dev Portfolio

A personal portfolio website introducing Edward Ranz Cardoza and showcasing his work, skills, and background.

## Website

The planned website centers on a landing page and personal introduction, with light and dark themes and animated interactions.

The site is not yet deployed. Once published, it will be accessible through a web browser with no installation required.

## Technologies

Planned stack: Next.js, React, TypeScript, Tailwind CSS, and GSAP.
