# Design Taste Frontend

Read [project instructions](../../../AGENTS.md) and [project context](../../../docs/project-context.md). The owner's requirements and supplied prototype define the result. This project adaptation retains intentional composition, subject-specific content, hierarchy, browser inspection and iteration without imposing a new house style.

Read [visual review](references/visual-review.md) for layout, type, color, imagery and content. Read [motion review](references/motion-review.md) when animation or lifecycle is involved. Use [QA guidance](../../../docs/agents/qa.md) for evidence and open limitations.

## Work from the reference

Inspect the supplied prototype and affected current state at matched dimensions, theme and motion settings. Locate missing references through [reference guidance](../../../docs/agents/references.md); limit conclusions when evidence is unavailable. Source inspection alone does not prove a visual defect.

Tie the requested improvement to this portfolio: hierarchy, legibility, interaction clarity, responsive usability or coherent motion. Preserve its composition and identity. Compare a focused change against the reference rather than generating a random direction.

Distinguish a requirement regression or usability defect from an aesthetic option. Present options as recommendations when approval is needed. Do not automatically replace fonts, force left alignment, delete sections, ban the approved wave/glow, add imagery or animation to meet counts, or manufacture content to fill a layout.

For assigned implementation, use actual project patterns and installed dependencies. Project context describes the planned stack; it does not establish that it is configured. Preserve semantic content, stable controls, keyboard use, reduced-motion fallbacks and cleanup. Official marks and favicons are supplied inputs, not image-generation prompts.

After an authorized visible change, inspect affected states in both themes and relevant viewports, then check the interactions involved. Explain the result and remaining limitations. A taste score or screenshot lint is not completion evidence.
